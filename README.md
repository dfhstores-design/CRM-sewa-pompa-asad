# 🚜 Concrete Pump CRM & Telemarketing System
Aplikasi CRM berbasis Web App untuk manajemen pelanggan historis penyewaan pompa beton (Concrete Pump), dilengkapi 40 variasi rotasi template WhatsApp, pengingat follow-up, pencatatan jadwal pengecoran, dan integrasi Bot Telegram.

- **Frontend:** HTML5, Tailwind CSS, Vanilla JS (Hosted on Vercel)
- **Backend & Database:** Google Apps Script REST API + Google Sheets
